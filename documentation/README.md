# Documentation — Example Structure

This folder contains example documentation for the DM Cockpit app, structured as a fictional D&D campaign called *Le Dernier Choix*.

The campaign, story, NPCs, locations, and lore within are entirely made up and exist solely to demonstrate how the app's documentation system works in practice — folder hierarchy, markdown formatting, cross-linking between files, and how content surfaces inside the app.

## Structure

```
documentation/
├── History & Lore/         — World history, mysteries, named phenomena
├── Locations/              — Cities, districts, and points of interest
├── Magic Items/
│   └── Distributed/        — Items in active circulation
├── NPCs/                   — Named characters, used and reserved
├── Players/                — Party overview, languages, personal arcs
├── Quests/
│   ├── Active/             — Current quests and objectives
│   └── Completed/          — Resolved quests for reference
├── Rules & Tables/         — Encounter tables, house rules
├── Sessions/               — Session notes and planning templates
├── Shops & Economy/        — Shop inventories and pricing
├── Villains/               — Antagonists and their details
└── World/                  — Factions, overworld overview
```

Any markdown files placed in this folder (or subfolders) will be picked up by the app automatically.
