# Session Checklist

*Run through this while filling out Session Prep / Direction. Not everything needs to be big - a single line of dialogue can satisfy a beat.*

---

## Every session, hit at minimum:

- [ ] **1 main-story beat** - OOTS/Luxfracta/DOL grip tightens, loosens, or is directly referenced. Doesn't need to be the session's focus, just present.
- [ ] **1 PC personal thread** - pick ONE character, surface ONE thread (see [PC Family Arcs](../../Players/Party%20Overview/PC%20Family%20Arcs.md) and each character's Notes section). Rotate who gets the spotlight session to session - track this so the same 1-2 players don't get all the airtime.
- [ ] **1 open thread advanced or closed** - pull from the last session's Threads/To Do list. Advancing counts; you don't need to resolve it.
- [ ] **1 hook to end on** - the session shouldn't just stop, it should point somewhere. New info, a cliffhanger, an NPC's ask.

## Sanity checks before the table sits down:

- [ ] Does tonight's plan **story-dump** more than one PC's backstory at once? If yes, cut it back to one and bank the rest.
- [ ] Are any **Active Threats** overdue to move (see [Active Threats](../../Quests/Threats/Active%20Threats.md))? A threat that's sat untouched for 2+ sessions should either escalate or get explicitly deprioritized - don't let it just go stale.
- [ ] Is there a thread that's been "next session" for 2+ sessions running? Either commit to it this time or cut it from prep so it stops cluttering the checklist.

## After the session (fold into doc updates):

- [ ] Did the main-story beat move the needle enough to update **Active Threats** or the relevant Story Thread doc?
- [ ] Did the PC thread reveal anything worth adding to that character's sheet or **PC Family Arcs**?
- [ ] Re-seed next session's Threads/To Do from what's still open.
